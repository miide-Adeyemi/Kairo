## Training experiments (all negative, nothing shipped)
- **Cross-encoder fine-tune** (MiniLM-L12, 2,400 agent-written paraphrases + hard negatives + 197 sermon-talk windows): validation AUC 0.84 -> 0.96, but the hard benchmark did not move (right verse first: written 91% -> 91%, gapped 100% -> 100%, real 43% -> 36%). Cause: the reranker only reorders the 20-verse shortlist; on written cases the right verse is already in the lookup's top 10 for 96%, so there is ~5 points of headroom. Real passages are limited by retrieval (57% in top 10), which no reranker can fix.
- **Embedder fine-tune** (bge-small-en-v1.5, same data): worse than the untrained model on every group (written 89/95/97 -> 82/89/94).
- **Finding worth following up:** the untrained bge-small (33M params, ~35 MB int8) matches the current 188 MB embedder on the benchmark at full precision (written 89/95/97%, gapped 100/100/100%, real-dev 43/50/57%). Untested: int8 quality, the held-out real passages (8 cases, weaker: 0/12/12 vs 25/38/38), and Rust support for its CLS pooling and query prefix ("Represent this sentence for searching relevant passages: "). Could cut ~150 MB from the app.
- Scripts and weights are in the session scratchpad (`ft/`: `embed_eval.py`, `embed_train.py`, `train.py`, `build_cases.py`); regenerable.

## How to run the evaluations
All commands run from `Kairo/`; binaries are in `src-tauri/target/release/` (build with `cargo build --release -p kairo-eval -p kairo-semantic`).
- **Sermon replay:** `replay --verbose` (dev), `replay --verbose --held-out` (held-out; score once), add `--meaning gemma-legacy.json` for the meaning model (about 10 min).
- **Scenarios:** `python3 eval/scenarios/make_scenarios.py`, then `replay --verbose $(ls parity/golden | grep ^scn- | sed 's/.json//')`.
- **Full services from audio:** `offline-transcribe <audio> <name>` (needs `KAIRO_OFFLINE_MODEL`), then `replay --offline --verbose <name>`.
- **Interpreter false-mark check:** `interp-check <audio> <transcript name>`.
- **Meaning model benchmark:** run `semantic_bench` from `src-tauri/crates/kairo-semantic` with `--embedder gemma-legacy.json --reranker minilm.json --cases eval/paraphrase_cases_hard.json [--list] [--window N] [--dump file]`.
- **Tests:** `cargo test --release -p kairo-detect -p kairo-server`; JS: `node --test src/*.test.js`.
